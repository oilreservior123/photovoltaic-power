# 光伏发电效率实时预测与智能调配系统

目标：综合两份PPT，为百口泉采油厂应用场景提供可操作、可追溯的技术交流与联合试验平台。

沿用 ChinaOil Sense 的红白主色、固定侧栏、清晰卡片。七个工作空间：运行总览、概率预测、储能调配、遥感蒙尘、协同作业、效益分析、数据实验室。模型结构、公式、字母释义、超参数、数据分割和模型来源只放在各模型卡片右上角的“模型详情”中。

实现采用无外部CDN的HTML/CSS/ES模块与SVG图表，可部署GitHub Pages。公开实测数据的MLP基线离线训练并导出预测、验证残差和权重，浏览器可用权重推理；Chronos-2、HyperSIGMA和跨尺度融合属于拟验证模型，不伪称已训练。数据上传后进行格式校验并计算统计表现。环境情景使用确定性物理合成数据、带终端SOC约束的离散动态规划滚动调度，基线保持相同储能规模。无人机与机器人提供带风速、降雨、温度、电量约束的任务规划、状态推进和日志导出，明确为演练；设备接入通过规范说明。

统计包含误差、散点、残差、预测区间、覆盖率、日块bootstrap、逐日成本比较、情景敏感性。实测回放与合成情景不能混合为现场结论。按公开样本时间展示，不把2020年样本包装成实时现场采集。卫星区域筛查、无人机定位与地面复核分层，避免声称卫星实时识别单块板。

合作落地：数据清单、6个月试点阶段、设备接口、验收指标。GitHub仓库为用户指定的 oilreservior123/photovoltaic-power，不创建额外托管项目。
