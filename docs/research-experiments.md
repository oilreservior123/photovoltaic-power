# Cross-Unet、SAM 3.1与日充放电预测的证据说明

## 已实际计算的Cross-Unet

`scripts/cross_model.py`是项目独立轻量实现：24通道时间卷积、96/48/24三尺度、4头未来气象交叉注意力、U形跳跃融合、物理残差及单调蒙尘门控、光伏与负荷双输出。参考Cross-Unet气象/历史多尺度融合思想，**不是官方架构的完整复现**，亦没有包含尚未实现的逆变器图模块。

官方代码入口：https://github.com/ZjuMachine/PV-power （原项目Apache-2.0；当前代码独立编写）。

生成421天机理序列，构造420个不重叠的次日目标样本；294训练、63验证、63测试。每个输入为前1日96×8历史和次日96×6已知条件，输出为96×2光伏/负荷；目标日按时间连续隔离，下一日使用已观测历史符合因果关系。验证选轮次和残差分位数，测试不参与调参。固定物理尺度归一化，不拟合测试统计量。

生成器含季节太阳几何、云量、温度、污染积累/清扫和生产负荷扰动；合成NWP包含约10%辐照系统偏差。模型会学习该生成规则，因此低误差或较大改善不能外推真实天气和现场污染。公开数据MLP使用另一数据任务，不能与本合成实验直接比较百分比。

训练：seed42、AdamW、lr0.001、weight_decay0.0001、batch32、80轮、验证选择最佳。实际参数与误差在`data/cross-model-card.json`；完整预测、验证残差与未来7日输出在`data/cross-experiment.json`；实际权重为`data/cross-weights.json`。

复现：安装当前记录的PyTorch CPU和NumPy后运行`python scripts/train_cross.py`，然后`node scripts/build_research_data.mjs`。Python结构测试：`python -m unittest discover -s tests -p test_cross_model.py`。未来7日递推将前一日预测功率与负荷放回历史，后续天气历史使用起报时的合成预报，未读取未来实测功率或负荷。

## SAM 3.1

官方代码：https://github.com/facebookresearch/sam3

版本与基准：https://github.com/facebookresearch/sam3/blob/main/RELEASE_SAM3p1.md

授权权重：https://huggingface.co/facebook/sam3.1

SAM3.1主要增强视频多目标分割与跟踪；官方权重需要授权，官方环境要求CUDA GPU。**本项目未取得权重、未执行其训练或推理**，不将合成掩膜称为SAM输出。

页面分开展示官方cgF1/J&F参考与本地掩膜统计。官方7倍加速仅针对H100、128目标等特定配置，不是本地速度，也不是污染识别精度。二值IoU/F1不能与cgF1/J&F混为一谈。

120帧合成示例按20阵列组分为14/3/3组，即84/18/18帧；同组不跨集合。前景是光伏板边界，非已识别污染。示例JSON包含模型来源声明、scene_id/group_id、宽高、提示、任务及按行展开二值预测/参考掩膜；图像是精确掩膜示意，并非遥感影像。导入用户结果后重新计算TP/FP/FN、Precision/Recall/F1/IoU及组块bootstrap。导入元数据不能证明模型权重身份，参考标注必须独立。

## 每日充放电量

未来7日为2026-11-19起的合成气象情景，情景起报2026-11-18 23:45（UTC+8），不是在线天气服务。Cross-Unet预测驱动33状态、日终SOC约束的日先动态规划。光伏容量177.1千瓦峰值、储能200千瓦时/100千瓦、外送20千瓦；参数可在页面独立修改。

SOC10–90%，每日期初/期末50%；充放电效率各95%；禁止同时充放。购电谷/平/峰0.30/0.65/1.00元每千瓦时，外送0.25，吞吐成本0.035；目标函数另有弃光偏好0.02。显示财务成本不含该偏好。电网补足缺电，未建模线路潮流与变压器限制。离散方案是近似解，容量大而功率小会因状态间距过粗而保守。

取验证63日光伏与负荷残差的连续7日块，按相同块索引共同扰动两者，再逐条路径重算，保留日内与部分日间相关性。默认100路径，P05/P50/P95。累计分位数在路径汇总后计算，不相加各日分位数。该情景区间尚未对真实未来覆盖做校准；尤其第2–7日递推误差增长未独立建模。

日充电/放电是交流侧吞吐电量，非电池额定容量；多次循环可使日吞吐超过额定容量。终端SOC不变时，放电≈充电×0.95²。充电可能来自电网，不可全计为光伏消纳。能量平衡含光伏、购电、生产、外送、弃光、损耗与储能变化。
