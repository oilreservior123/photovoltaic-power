# 多模态模型与日充放电预测扩展

目标：在现有GitHub公开平台新增模型实验与储能时序预测。沿用红白布局，模型结构/超参数在右上角模型详情，数据与结果边界在主页面保留。

1. 实际训练一个项目轻量Cross-Unet：时间卷积多尺度编码、未来气象交叉注意力、跳跃融合、蒙尘物理门控、光伏与负荷双头。420个合成日样本，按目标日70/15/15隔离；验证选轮次、验证残差校准，测试只评价。不是官方论文完整复现或现场性能。
2. SAM3.1官方权重受授权且当前无GPU；展示官方基准参考，明确标记未本地运行。提供独立场景分组70/15/15建议、注释样本、合成掩膜评价实算及用户SAM导出结果JSON导入计算。合成掩膜不称为SAM推理。
3. 将训练模型未来7日情景功率/负荷预测输入带日终SOC约束的储能动态规划；按验证日残差整块重采样输出P05/P50/P95充放电量、区间、能量闭合、SOC、场景概率与直方图。
4. 先写形状、分割计数、比例分组、能量守恒、分位数和JSON边界测试，再实现；运行训练与全套测试、浏览器验证后发布GitHub Pages。
