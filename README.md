# 光伏发电效率实时预测与智能调配系统

**公开访问（无需登录）：https://oilreservior123.github.io/photovoltaic-power/**

平台已通过GitHub Pages公开发布，无需登录即可访问。本仓库保留完整源码、数据、模型权重与自动发布工作流。

百口泉采油厂应用场景的研究、技术交流与联合试点平台。风格延续ChinaOil Sense的红白色侧栏与卡片布局。

## 能力

- 运行总览：可用出力、生产负荷、购电曲线与行动建议。
- 概率预测：公开实测数据的1小时MLP预测、对照模型、验证残差校准区间、散点、残差、覆盖率与日块bootstrap。
- 储能调配：33状态离散动态规划滚动求解，与同设备规则和无储能策略比较，检查逐步功率与日电能平衡、终端SOC。
- 遥感蒙尘：合成空间风险、400–2500纳米混合光谱、清扫反事实出力与净收益分析。
- 协同作业：无人机与清扫机器人推荐/自定义方案、天气电量联锁、蛇形访问路线、任务状态推进、演练日志与JSON导出。
- 效益分析：同设备增量收益、现金流、净现值、敏感性、工作效率与6个月合作实施路径。
- 数据实验室：UTF-8 CSV上传校验、评价、图表与结果下载；实际MLP权重可在浏览器重算。

所有模型技术结构、公式、符号说明、超参数和证据限制放在各模型卡片右上角“模型详情”。

## 运行与验证

不依赖外部CDN或运行时安装包。Node.js 22或更新版本：

```sh
npm test
npm run build
python3 -m http.server 8000 --directory dist
```

打开 http://localhost:8000/ 。GitHub Pages通过`.github/workflows/pages.yml`构建发布`dist/`，所有资源使用相对路径。

## 数据与模型

公开数据、训练协议、模型来源与许可入口见 [data/README.md](data/README.md)。内置功率样本来自公开Plant 1单逆变器，**不是百口泉采油厂现场数据**。容量映射、负荷与设备配置是应用情景。预测测试6日期含不完整末日；调配只用5完整日。

- 真正运行：MLP、岭回归、持续性、验证残差区间、情景DP、财务计算、任务演练。
- 研发设计：Chronos-2适配、多尺度交叉注意力、逆变器图注意力、蒙尘门控、HyperSIGMA任务头；未声称加载或训练这些基础模型。
- 遥感风险图、光谱、环境情景、机器人时间和电量均为合成/假设，不代表实测准确率。
- 无人机、机器人与储能控制器均未连接。任务按钮只写当前浏览器的演练状态，不发送设备指令。

模型复算（Python 3.11+）：

```sh
pip install -r scripts/requirements.txt
python scripts/build_data.py
python scripts/replay_dispatch.py
npm test
npm run build
```

实际设备接入需受控服务端、鉴权、现场许可和设备SDK，见 [接口规范](docs/device-interface.md)。GitHub Pages本身不运行Python训练或真实控制服务。

## 已验证基线

训练/验证/测试1645/480/560条，日间测试257条。MLP日间nRMSE17.2301%，持续性21.3496%，相对改善19.2957%；岭回归nMAE略优。90%名义区间覆盖92.607%。5日调配同设备成本合计下降2.8713%，但3天未优于固定规则。不得外推为现场保证或全年收益。

## 多模态模型与日充放电扩展

新增“多模态模型”和“日充放电预测”工作空间。蒙尘感知Cross-Unet项目轻量实现已在420个合成目标日上实际训练并提供独立测试、区间、样本注释和权重。SAM3.1提供官方参考、合成掩膜评价与用户结果导入；本地推理待权重授权/GPU环境，未将示例指标冒充其性能。未来7日充放电量基于合成气象、递推预测与整日残差情景求解，支持参数重算和CSV导出。详情见 [实验口径](docs/research-experiments.md)。

### 自定义比例与智能调配比较

进入“多模态模型 → 比例实验与训练”，可设置训练/验证/测试比例、种子与轮次，从头实际训练 Cross-Unet-Ratio 交互轻量变体。提供3比例×3种子的已完成实验、共同测试窗口、分集统计、训练过程、注释样本和结果/权重导出。与原Cross-Unet轻量模型分开表述，全部新增比例实验为合成数据验证。储能调配新增成本增量分解、累计成本、吞吐与峰时购电图表、分时计划与建议。完整协议见[实验说明](docs/cross-ratio-experiments.md)。
